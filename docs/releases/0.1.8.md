# 飞牛 WireGuard 0.1.8

- 新增“关于”页面，显示作者、当前版本、运行架构、GitHub 项目和问题反馈入口。

## 安装与升级

x86 NAS 下载 `fn-wireguard-0.1.8-amd64.fpk`，ARM64 NAS 下载 `fn-wireguard-0.1.8-arm64.fpk`。在飞牛应用中心选择手动安装或手动更新；已有安装无需卸载，保留设备、密钥和配置。更新后重新打开应用，左侧选择“关于”。

检测更新由 NAS 发起，仅在点击时读取 GitHub 的公开版本信息，不发送设备配置、密钥或数据库。下载 FPK 后仍需在应用中心手动更新。

SHA256 校验值见附件 `SHA256SUMS.txt`。此版本已完成本地回归、界面检查与双架构包校验；没有在用户 NAS 上自动安装或更改配置。
